Bradley–Terry strength, bootstrap 95% intervals

The standard model for paired data: P(i beats j) = sᵢ / (sᵢ + sⱼ). Unlike a raw win rate it accounts for who each model faced. 1.0 is average; log scale.

Method & limitations

Read before quoting any number on this page

How the comparisons were run

  • Two rounds. Round 1 (20 comparisons) ran in Handshake AI Versus, which presents two models side by side. Round 2 (8 comparisons) ran on a blind A/B interface where the model names were withheld until the verdict was recorded.
  • Each prompt was shown to two models; both responses were read in full and a single winner was chosen, scored across five dimensions.
  • Judging criteria: technical correctness, completeness, operational usefulness to a SOC, clarity, realism, and hallucination resistance where the prompt tested it.
  • A short written rationale was recorded for every decision — all of them are in the results table above.

Why the results are hedged as heavily as they are

  • The sample is too small to rank this many models. The confidence intervals above are the honest width of the design, not a formality.
  • One judge, and no second rater. I scored every comparison myself. Round 1 was unblinded — I could see which model wrote which answer, which is a live route for bias that nothing controlled for. Round 2 was blind. Either way there is no second rater, so there is no inter-rater agreement to report, and these verdicts have not been shown to be reproducible.
  • Unbalanced pairings. Not a round robin — see the pairing matrix. Strength of schedule varies substantially between models.
  • Few repeats. Most prompts were judged once, so within-prompt judging variance is largely unmeasured.
  • Round 1's raw model outputs were not archived, so those judgements cannot be independently re-scored. Round 2's responses are all saved, which is the difference between a claim and a checkable one.
  • Category-level claims are unsupported. With one to three comparisons per category, no per-category conclusion is available here — which leaves the question this project set out to ask still open.
  • Mixed collection conditions in round 2. Responses were gathered from different interfaces, none of which expose sampling parameters. Comparisons spanning two sources carry that confound.
